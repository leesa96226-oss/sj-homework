# 신정개발 경영지원 대시보드

일용인력 공수계산을 시작으로 경영지원 업무 전반을 다루는 웹 대시보드입니다.

## 🔒 데이터 보안 원칙

**이 저장소에는 어떤 회사 데이터도 존재하지 않습니다.**

- 엑셀/데이터 파일(`*.xlsx`, `*.xls`, `*.csv` 등)은 `.gitignore`로 커밋이 차단됩니다.
- 공수 데이터는 사용자가 브라우저에서 직접 엑셀을 업로드해 사용합니다.
- 업로드된 파일은 **사용자 컴퓨터의 브라우저 안에서만** 파싱·보관(localStorage)되며,
  서버 전송·외부 저장·저장소 커밋이 일절 없습니다.
- 보관된 데이터는 화면에서 언제든 삭제할 수 있습니다.

## 주요 기능

### 인력공수 관리
- 총 인원 / 총 출역 공수 / 총 노무비 / 1인 평균 공수 요약
- 업체별 공수·노무비 집계 (차트 + 표, 노무비 비중)
- 일자별 출역 공수 추이 (업체별 누적 차트)
- 인원별 상세 내역 (업체 필터, 성명 검색, 정렬, 행 클릭 시 일자별 내역)

### 노무비 정산
- 업체별 · 단가별 노무비 정산서 (인원 / 공수 / 금액, 소계·총계)
- 인쇄 / PDF 저장

### 데이터 관리
- 엑셀 업로드 즉시 반영, 여러 달 데이터를 브라우저에 보관하고 전환
- 가상 데이터 미리보기 (실제 데이터 없이 화면 확인용, 코드에서 즉석 생성)

## 엑셀 양식 (`웹_데이터` 시트)

| 업체 | 구분 | 순번 | 성명 | 1 | 2 | … | 31 | 출역일수 | 노무비단가 | 노무비총액 |
| ---- | ---- | ---- | ---- | --- | --- | --- | --- | -------- | ---------- | ---------- |

헤더 이름으로 열을 찾으므로 열 순서가 조금 달라도 동작합니다.

## 개발

```bash
npm install
npm run dev    # 개발 서버
npm run build  # 배포용 빌드 (dist/)
```
