# 신정개발 경영지원 대시보드

일용인력 공수계산을 시작으로 경영지원 업무 전반을 다루는 웹 대시보드입니다.

## 주요 기능 (인력공수 관리)

- 총 인원 / 총 출역 공수 / 총 노무비 / 1인 평균 공수 요약
- 업체별 공수·노무비 집계 (차트 + 표)
- 일자별 출역 공수 추이 (업체별 누적 차트)
- 인원별 상세 내역 (업체 필터, 성명 검색, 정렬, 일자별 내역 펼침)
- 엑셀 업로드: `웹_데이터` 시트가 있는 공수 엑셀(.xlsx)을 올리면 즉시 반영
  - 업로드한 파일은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.

## 엑셀 양식 (`웹_데이터` 시트)

| 업체 | 구분 | 순번 | 성명 | 1 | 2 | … | 31 | 출역일수 | 노무비단가 | 노무비총액 |
| ---- | ---- | ---- | ---- | --- | --- | --- | --- | -------- | ---------- | ---------- |

헤더 이름으로 열을 찾으므로 열 순서가 조금 달라도 동작합니다.

## 개발

```bash
npm install
npm run dev    # 개발 서버
npm run build  # 배포용 빌드 (dist/)
```

## 배포

GitHub `main` 브랜치에 푸시하면 Vercel이 자동으로 빌드·배포합니다. (Framework: Vite)
